# Видеокамера — видеоняня на домашнем ПК

## Коротко

ПК в детской превращён в камеру с двусторонним звуком: видео и микрофон — со страницы на ПК,
просмотр и разговор — с телефона. Работает сейчас как служба Windows с автозапуском, HTTPS на
порту 8443, вход по паролю, PWA-иконка на телефоне, уведомления при движении в кадре.
Основа — открытый проект PetCam (ISC), поверх которого 18 собственных коммитов.

## Проблема

Ночью нужно не только видеть ребёнка, но и слышать его и отвечать голосом. Готовые «няни»
стримят видео в чужие облака, требуют подписки, задерживают звук и почти никогда не дают
двустороннюю связь. Upstream PetCam умел только односторонний просмотр: без TLS, без
авторизации, без автозапуска — то есть открытая камера в квартире после каждой перезагрузки ПК.

## Решение

1. Двустороннее аудио через WebRTC: камера на ПК отдаёт видео и звук, телефон получает поток
   и может отправить свой микрофон обратно (кнопки «Слушать» / «Говорить»).
2. HTTPS на 0.0.0.0:8443, самоподписанный сертификат генерируется автоматически при первом
   старте; отдельный инструмент перегенерации под смену IP; поддержка сертификата Tailscale.
3. Basic Auth на страницы, статику и WebSocket-сигналинг: сравнение логина и пароля
   constant-time, парсинг заголовка Authorization вручную.
4. Автозапуск службой Windows через NSSM: StartType = Automatic, перезапуск через 5 с,
   альтернативный вариант — задача «при входе пользователя».
5. Детект движения: страница камеры считает разницу кадров через canvas, отправляет
   POST /api/motion, сервер публикует уведомление со снапшотом и держит cooldown против флуда.
6. PWA-вьюер: manifest, service worker (кеширует только оболочку, не трогает API и WebSocket),
   иконки 192/512 — сгенерированы собственным PNG-энкодером без внешних зависимостей.
7. Мобильный UX: полноэкранный просмотр, панель настроек, честный статус «Звука нет» вместо
   залипшей кнопки, перезапрос свежего WebRTC-offer, если зритель подключился позже камеры.
8. Ротация логов по 1 МБ и ежедневная задача очистки старых логов планировщиком.
9. 18 инструментов в tools/: проверки сертификата, ntfy, синтаксиса, firewall, состояния порта,
   обёртка запуска с повышением прав через окно UAC для ИИ-агента, работающего без прав админа.
10. README на 307 строк: быстрый старт, автозапуск, доступ извне, диагностика, частые проблемы.

## Демонстрируемые навыки

- WebRTC: peer-соединение, переупорядочивание offer/answer при позднем подключении зрителя.
- Сигналинг через WebSocket (библиотека ws) на своём сервере.
- HTTPS с самоподписанным сертификатом: генерация, проверка, перегенерация, выбор между двумя сертификатами.
- Basic Auth: ручной парсинг заголовка, constant-time сравнение, whitelist публичных файлов PWA.
- Windows-службы через NSSM: установка, автозапуск, перезапуск, диагностика состояния.
- PWA + service worker: манифест, иконки, стратегия кеширования, установка на домашний экран.
- Детект движения: canvas diff на клиенте, API на сервере, антифлуд cooldown, push-уведомления.
- Автоматизация Windows: PowerShell-скрипты, Планировщик задач, ротация и очистка логов.
- Обёртки с повышением прав: разовая задача с окном UAC для агента без прав администратора.
- Работа с форками и upstream: сохранение совместимости при переименовании продукта.

## Стек

Node.js + Express 4, ws 8, axios, selfsigned, фреймворк ip; ванильный JS + Canvas + WebRTC на клиенте;
NSSM 2.24, PowerShell 5.1, Планировщик задач Windows; TLS: self-signed или сертификат Tailscale;
доступ извне — приватная VPN-сеть (Tailscale).

## Что не получилось / ограничения

- PWA на Android не устанавливается, если манифест, service worker и иконки закрыты Basic Auth —
  пришлось сделать эти четыре файла публичными (секретов в них нет).
- Полноэкранный режим и Wake Lock на iOS работают только по жесту пользователя и частично.
- Сертификат Tailscale действует лишь на одно имя хоста, при заходе по IP браузер всё равно
  предупреждает о несовпадении имени.
- Автопродление сертификата не автоматизировано — его нужно обновлять вручную или задачей.
- Прошивка ESP32-S3 из upstream не используется; блок управления моторами в интерфейсе остался
  как необязательный и рабочим не проверялся.
