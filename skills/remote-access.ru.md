# Удалённый доступ и домашняя инфраструктура

## Что это

Умение связать несколько домашних устройств в один рабочий контур: приватная сеть вместо
публикации в интернет, доступ с телефона, передача артефактов, пробуждение и стриминг ПК.

## Где подтверждено

- `cases/dev/01-videokamera.ru.md` — доступ к камере извне дома через приватную VPN-сеть, отдельная
  ветка README про ограничения VPN в РФ, документированные процедуры смены адреса и
  перегенерации сертификата, проверки firewall и состояния порта.
- `cases/dev/07-echelon-remote-pipeline.ru.md` — полный контур: 6 документов по инфраструктуре
  (доступ, стриминг рабочего стола, передача файлов, пробуждение по сети, доска задач),
  9 файлов доставки результатов на устройства, 11 файлов настройки ПК (SSH, автологин,
  стриминг), 32 файла диагностики окружения и сети.
- `cases/dev/04-echelon-beyond.ru.md` — правило «источник истины — домашний ПК»: всё, что должно
  пережить выключение ноутбука, выполняется дома; ноутбук — рабочая копия.
- `cases/dev/02-normcontrol-kb.ru.md` — обратный случай: публичный сервис вообще без домашней
  инфраструктуры (хостинг на GitHub Pages), сознательный выбор для чужого рабочего ПК
  с закрытым интернетом.

## Уровень

**Уверенный.** Обоснование:

- Контур работает и документирован: 68 файлов автоматизации и 6 документов по инфраструктуре,
  включая описание того, что не работает (недоступная сетевая шара, отсутствие облачного канала).
- Найдены и описаны ограничения приватной сети: офлайн-устройство не получает файл, повторная
  отправка делается вручную; доска задач доступна только внутри сети — это осознанный компромисс.
- Практика подтверждена двумя проектами: домашний сервис (камера) и домашняя фабрика (проект игры).
- Уровень не выше «уверенного», потому что нет ни одного публичного результата этой работы и
  нет документации по отказоустойчивости (резервирование, мониторинг).
