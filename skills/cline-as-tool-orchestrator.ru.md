# Оркестрация Cline для внешних инструментов

## Что это

Умение научить ИИ-агента пользоваться инструментом, которого он «не знает из коробки»: генератор
изображений, тренер LoRA, музыкальный генератор, локальные LLM-провайдеры. Не «попросить агента
написать код», а настроить агента так, чтобы он сам запускал внешний инструмент, читал его метрики
и возвращал результат в файлы.

## Где подтверждено

- `cases/dev/05-cline-art-music.ru.md` — раздел «Роль Cline в пайплайне»: Fooocus (генерация),
  kohya_ss (обучение LoRA), ACE-Step (музыка). Агент запускает батчи, собирает метрики контроля
  качества (палитра, метаданные PNG, хеши), версионирует промты в git, отбраковывает слабые кадры,
  идемпотентно ставит пресет стиля и патчит драйвер генератора.
- `cases/dev/07-echelon-remote-pipeline.ru.md` — пункт 8 раздела «Решение»: Ollama и LM Studio.
  Агент поднимает сервер модели, проверяет доступность, отправляет тестовый запрос и снимает статус.
- `cases/dev/02-normcontrol-kb.ru.md` — DeepSeek в GitHub Actions: агентная логика живёт в workflow
  и превращает текст из issue в заметку базы знаний.
- `cases/dev/04-echelon-beyond.ru.md` — AGENTS.md: контракт результата для агента в репозитории
  (папка deliveries, обязательный SUMMARY.md, правила git).

## Уровень

**Продвинутый.** Обоснование:

- К агенту подключены пять внешних инструментов с разными форматами входа и выхода: Fooocus,
  kohya_ss, ACE-Step, Ollama, LM Studio.
- Результат стабилен на объёме: около 300 сгенерированных треков, 141 кадр-кандидат,
  две обученные LoRA (изображения и музыка).
- Настроены не только запуски, но и обратная связь: агент читает метрики (палитра, sha1, размеры,
  счётчики GPU) и по ним принимает решения об отбраковке и повторных прогонах.
- Есть разделение ответственности: агент делает механическую работу, человек — стиль и приёмку;
  это сформулировано в самом кейсе, а не подразумевается.

## Что доказывает

- tools/fooocus — 106 файлов скриптов (обучение, батчи, контроль качества, промты, калибровка).
- deliveries/lora-fresco-merea/SUMMARY.md — числа по четырём прогонам обучения LoRA и вердикт
  по качеству (папка результатов в репозитории проекта игры).
- docs/ART/LORA-INSTALL.md (219 строк) — рецепт, который агент воспроизводит (файл в репозитории
  проекта игры).
- AGENTS.md репозитория проекта игры — контракт результата, по которому работал агент.
