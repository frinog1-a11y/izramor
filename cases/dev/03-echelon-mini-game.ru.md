# Мини-игра «Сквозь Зыбь» (пасхалка /echelon)

## Коротко

Скрытая страница на сайте базы знаний (пасхалка): мини-игра про плавание сквозь слои Зыби
с боями, боссами, лорными записками и финальной канвас-анимацией. Полностью написана на
ванильном JS (1 893 строки) и встроена в Quartz без единого аудиофайла — весь звук
синтезируется кодом. Открывается по прямой ссылке, секретной частицей в фоне или кодом.

## Проблема

Сайт нормоконтролёра — серьёзный инструмент, но автору нужен был способ показать своим,
что умеет его техническая часть: игровая механика, процедурные звук и анимация в браузере —
и при этом ничего не сломать в рабочем разделе. Задача: игровой опыт, который живёт внутри
статического сайта на GitHub Pages, не мешает навигации и не требует серверной части.

## Решение

1. Игровая логика вынесена в статический файл quartz/static/games/echelon.js (1 893 строки);
   в заметке остаётся только подключение скрипта (сборщик Quartz запрещает инлайн-скрипты в markdown).
2. Скрытый вход: страница исключена из поиска, графа, sitemap и RSS, снабжена noindex;
   открывается прямой ссылкой, секретной частицей в астральном фоне или вводом кода E-C-H-E-L-O-N.
3. Игровой цикл: слои Зыби с ростом темноты, стрельба, столкновения, HUD, рекорды.
4. Боссы: свой бой после каждого слоя, у каждого босса собственная механика, финальный босс
   («Сердце Бездны») двигается по арене.
5. Синтез звука через Web Audio API: тоны, шум, аккорды, попадания, победа/поражение —
   собственный AudioContext, который уважает общий переключатель звука на сайте.
6. Ambient-слой «Дышащая Мерея»: дрон, ветер, кристаллы и пульсары, меняются в зависимости
   от слоя и от того, идёт ли бой.
7. Лорные записки: открываются поверх игры с паузой, закрываются продолжением.
8. Финальный «мультик»: канвас-анимация (Сердце Бездны → портал → салют) с кнопками после просмотра.
9. Видимость как механика: на тёмных слоях объекты получают яркость и обводку, звёзды гаснут.
10. Проверка без браузера: сборка + функциональные тесты на заглушках document/canvas/AudioContext.

## Демонстрируемые навыки

- Canvas-игра без библиотек: игровой цикл, столкновения, состояния, HUD, рекорды.
- Процедурный звук на Web Audio API: синтез вместо файлов, уважение пользовательских настроек.
- Динамические слои и ambient-музыка, зависящие от игрового состояния.
- Режиссура: боссы с уникальными механиками, лорные вставки, финальная анимация.
- Встраивание тяжёлого JS в статический генератор сайтов и обход его ограничений.
- Скрытая функциональность: исключение страницы из поиска/графа/sitemap/noindex, секретные триггеры.
- Тестирование UI-логики в среде без браузера (заглушки DOM и аудио).
- Итеративное полирование по отзывам: серия коммитов «исправить/улучшить» после первого прогона.

## Стек

Vanilla JavaScript (ES2015+), Canvas 2D, Web Audio API, Quartz 4, SCSS, GitHub Pages.
Никаких игровых движков и аудиобиблиотек — сознательно.

## Что не получилось / ограничения

- Первая версия игры («Астроном» с прогрессией, созвездиями и песочницей) была вырезана и
  заменена на «Сквозь Зыбь» — от неё остались только коммиты в истории.
- Проверить визуально в системе нечем (нет браузера): баланс сложности и картинка проверяются
  владельцем вручную на телефоне.
- Игра живёт внутри файла на 1 893 строки — дальнейшее расширение потребует дробления на модули.
- Мобильное управление подробно не задокументировано.
