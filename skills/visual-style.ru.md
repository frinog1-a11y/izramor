# Единый визуальный стиль через LoRA и промты

## Что это

Умение получить узнаваемый авторский стиль от генеративной модели: собрать датасет, обучить
свою LoRA, вести промты как версионируемые артефакты и отбирать результат по метрикам,
а не по настроению.

## Где подтверждено

- `cases/dev/05-cline-art-music.ru.md` — обучена с нуля SDXL-LoRA «Фрески Мереи»: датасет 50 кадров
  с капшенами, rank 32 / alpha 16, только U-Net, 1500 шагов, AdamW8bit, fp16, сид зафиксирован.
  Отбраковка слабых кадров в отдельную папку с причинами и повторная генерация.
- `cases/dev/05-cline-art-music.ru.md` — 18 итераций промта главного меню (v4…v18) с негативами,
  свипами по 20 кадров, отдельными промтами для элементов сцены; 141 кандидат (203 МБ)
  в assets/art/ui/menu. Инструменты отбора: палитровое сравнение, метаданные PNG, контактные листы.
- `cases/dev/05-cline-art-music.ru.md` — установленный в генератор стилевой пресет с идемпотентным
  скриптом установки и A/B-тест «с LoRA против без LoRA» по одному сиду и по хешу файла.
- `cases/dev/04-echelon-beyond.ru.md` — производственный регламент арта: структура папок под фоны,
  спрайты, интерфейс, фрески, референсы; правила приёмки кадров; отчёты с числами палитры.
- `cases/dev/05-cline-art-music.ru.md` — библиотека референсов стиля: шесть групп (римские фрески,
  византийские мозаики, готический витраж, модерн, средневековые карты и рукописи,
  изометрия в играх), скрипт загрузки, контактные листы.

## Уровень

**Уверенный.** Обоснование:

- Своя обученная модель, а не только готовые: файл LoRA, рецепт на 219 строк и отчёт с числами
  по четырём прогонам обучения.
- Дисциплина результата: вердикт по кадру даётся палитровыми метриками и хешами, есть таблица
  ускорения обучения (11x после освобождения видеопамяти, 1,8x за счёт TF32-шима).
- Промты и негативы лежат в git как файлы (десятки ревизий) — стиль воспроизводим, а не «нашёлся».
- Есть обратная петля: слабые кадры не выбрасываются молча, а уходят в rejected с причинами
  и перегенерируются с изменённым промтом.
- Почему не «продвинутый»: финальный кадр меню так и не выбран, часть подборок референсов пуста,
  а вкусовая оценка остаётся за человеком — процесс есть, системы приёмки нет.
