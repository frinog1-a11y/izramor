# Автоматизация Windows: скрипты, задачи, CI

## Что это

Умение убрать ручную работу: PowerShell и Python-скрипты для пакетных операций, задачи
планировщика, службы, CI-пайплайны и самопроверяющиеся проверки вместо ручного контроля.

## Где подтверждено

- `cases/dev/01-videokamera.ru.md` — 18 инструментов в tools/ (диагностика сертификата, порта, ntfy,
  firewall, синтаксиса), ротация логов и ежедневная задача очистки через Планировщик задач,
  скрипт установки службы, обёртка запуска с окном UAC для агента без прав администратора.
- `cases/dev/06-txt-to-docx.ru.md` — 22 скрипта пакетной обработки: 194 PDF пересобраны с зеркальными
  полями, отчёт «найдено/обработано/ошибки», автоустановка зависимостей, 14 скриптов проверки
  результата, отменяемое переименование файлов.
- `cases/dev/07-echelon-remote-pipeline.ru.md` — 68 файлов автоматизации: доставка результатов на
  устройства, пробуждение ПК по сети, автологин, автозапуск локальных моделей, 32 скрипта
  диагностики окружения.
- `cases/dev/02-normcontrol-kb.ru.md` — CI на GitHub Actions: сборка, деплой, отдельная задача
  «из issue в заметку с помощью ИИ», скриптовый аудит ссылок и метаданных базы.
- `cases/dev/04-echelon-beyond.ru.md` — контракт «каждая задача оставляет результат» плюс механика
  доски задач, запускаемая одним cmd-файлом.

## Уровень

**Уверенный.** Обоснование:

- Объём: 18 + 22 + 68 скриптов в трёх разных проектах, каждый — под конкретную операцию.
- Пакетность и объём обработки: 194 PDF и ~300 музыкальных файлов обработаны скриптами, а не руками.
- Наличие самопроверок: 14 скриптов проверки полей и размеров, 6 диагностик в сервисе видеокамеры,
  аудит связей в базе знаний — то есть автоматизация не «сделал и надеюсь».
- Эксплуатационная зрелость: службы, Планировщик задач, ротация логов, обёртки для повышения прав.
- Почему не «продвинутый»: скрипты живут в конкретных папках и с абсолютными путями, общей
  библиотеки переиспользуемых модулей нет, CI заведён только для одного проекта.
